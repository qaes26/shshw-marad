# سلامة قلبكِ وعافيتكِ يا شادية 🌸✨

> موقع تفاعلي رومانسي مبتكر مُهدى من أعماق القلب إلى الحبيبة الغالية **شادية** بمناسبة الشفاء والعافية، مصمم بأسلوب الآلة الكاتبة الكلاسيكية الساحرة ومخصص لشاشات الهواتف الذكية.

---

### ✨ مميزات الموقع:
- 💌 **المظروف الملكي والختم الشمعي**: تجربة افتتاح سينمائية وتفاعلية تبدأ بكسر الختم الشمعي `ش ❤️` للمس المظروف وبدء الرحلة.
- 📜 **الآلة الكاتبة الحيّة (Typewriter)**: عزف الكلمات حرفًا بحرف مع أصوات النقر الميكانيكية الواقعية ورنة الجرس الكلاسيكية (باستخدام Web Audio API) وقصيدة أسطورية مليئة بالحب والدعاء.
- 🎵 **المشغل الموسيقي الفاخر**: تشغيل الأغنية المرافقة الخاصة `سلامة قلبك يا شادية` مع أسطوانة فينيل دوّارة وموجات صوتية متفاعلة وأدوات تحكم سهلة.
- 💊 **صيدلية الروح والشفاء**: كبسولات تفاعلية (سكينة، فيتامين الضحكة، إكسير الدعاء، ترياق الدفء، وعد اللقاء) تفتح نوافذ حب ودفء.
- 💖 **عداد نبضات الحُب الحي**: زر قلب نابض ثلاثي الأبعاد يُرسل نبضات حب واهتزازات مع عبارات دعم ومواساة متجددة.
- 🌹 **لوحة الوردة الكريستالية المشعة**: خلفية وجزيئات بتلات متساقطة ولمسات غبار النجوم عند لمس الشاشة.
- 📱 **تجربة هاتف استثنائية (Mobile-First)**: استجابة كاملة للمس، واجهات ناعمة بتأثير الزجاج الفاخر (Glassmorphism)، وخطوط عربية عريقة.
